01 Capability index

C-01

Floating toolbar

Draggable, collapsible, with per-site position memory and a one-click reset to the composer.

C-02

Reply profiles

General, Developer, Writer, Student, Support, Recruiter, Sales and Quiz packs. Every reply editable, deletable, addable.

C-03

Click behavior

Fill the composer for review (default) or send immediately. Your choice, one toggle.

C-04

Long-press variants

Hold a chip to insert its expanded follow-up: hold Yes for "Yes, but explain why."

C-05

Template variables

Replies like "Explain {{topic}} for {{audience}}" prompt for values, then compose the finished prompt.

C-06

C-07

Smart detection

Opt-in, local-only. Surfaces Yes/No, True/False and A-E answer chips from the latest AI response.

C-08

Site visibility

Show the toolbar everywhere, or choose exactly which supported websites get it.

06 FAQ

What does Prompticon cost?

Nothing. Prompticon is free and open source under the MIT license.

Which AI chats does it support?

ChatGPT, Claude, Gemini, Grok, Mistral Le Chat, Qwen Chat, Meta AI and DeepSeek, plus most other web chats via intelligent fallback detection.

Does it track me or send data anywhere?

No. It is 100% client-side with no analytics, no trackers and no network calls. The only permission it requests is storage.

Can I customize the quick replies?

Yes. Eight curated profiles are fully editable, you can add your own replies, use template variables and long-press variants, and choose which websites show the toolbar.

What are the keyboard shortcuts?

Alt+1..9 inserts your first nine replies. Alt+P opens a searchable command palette.

Does clicking a reply send it immediately?

Only if you enable send-on-click. The default fills the composer so you can review before sending.

Zero tracking. Zero network calls.

Prompticon is 100% client-side. Your replies and settings never leave chrome.storage on your own machine. The only permission is storage, and the license is MIT.
